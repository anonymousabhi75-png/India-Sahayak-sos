#INDIA SAHAYAK

##Project description
OUR PROJECT IS ON BASED ON PROVIDING SERVIES TO THE CITY LIKE SOS, HOSPITAL FACILITIES , BLOOD BANK ,CONNECT THE PEOPLE WITH THE GOVERMENT PORTALS (ALL AT ONE PLACE LIKE UMANG,DIIGILOCKER, MYGOV,ETC).

##problem statement
* **selected theme:**citypulse

##tech stack
* **fronted:**TypeScript + React + Next.js + Tailwind CSS + HTML/JSX
* **hosting platform:** host3000

##key features
* **resource directory:** help people find local services and vital aid quickly.
* **community hub:** connects citizens together to stay involved in city events and neighbourhood updates.
* **user-friendly dashboard:** a simple interface allowing residents to easily navigate their urban environment.
